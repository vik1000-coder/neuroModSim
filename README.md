# Unobserved-modulator testbed

This is not a model of a nervous system. It is a synthetic scoring
instrument for a method that claims it can recover neuromodulator effects
propagating through time from activity alone, with the neuromodulators
unobserved.

Activity `x` is generated by a known circuit whose effective connectivity
`J(t)` is reshaped by hidden modulator channels — each with its own receptor
connectome, spatial diffusion reach, and timescale. Methods receive only
`x`; occupancies, release latents, and the exact `J(t)` are the answer key.

```
x_{t+1} = φ( A(t) x_t ) + noise
A(t)    = gain(t) · [ A0  +  Σ_c α_c · occupancy_c(t) · W_c ]
```

Full dynamics, mechanism taxonomy, metrics, and design rationale:
**[docs/MODEL.md](docs/MODEL.md)**.
Every command, parameter, and extension point: **[docs/GUIDE.md](docs/GUIDE.md)**.

## Quickstart

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
pytest                                       # all invariants must pass

python -m neuromodsim.demo                   # single-modulator scoring table
python -m neuromodsim.multi_demo --preset many   # 4 modulators, 4 timescales
python -m neuromodsim.viz_multi --preset many    # model card + figure suite + movie

pip install -e ".[dashboard]"
streamlit run neuromodsim/dashboard.py       # interactive dashboard
```

## What a run shows

Reference result (preset `many`: 12 neurons, 4 hidden modulators at four
timescales, tanh dynamics):

| method | R² neuropeptide (ρ=.9995) | R² serotonin (ρ=.997) | R² dopamine (ρ=.95) | R² octopamine (ρ=.85) |
|---|---|---|---|---|
| oracle | 1.00 | 1.00 | 1.00 | 1.00 |
| static VAR | 0.00 | 0.00 | 0.00 | 0.00 |
| sliding VAR (w=200) | 0.57 | 0.63 | 0.05 | 0.01 |

The oracle proves the hidden channels leave separable traces in `J(t)`; a
static graph recovers nothing; a trailing-window method recovers exactly the
channels slower than its window. Plug the method you actually care about
into the same interface (`fit_jacobians(x) -> J_hat`) and see where it lands.
